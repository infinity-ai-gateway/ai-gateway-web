# AI Gateway Web 组件与复用设计文档

## 1. 设计目标

- 明确通用组件与业务组件的边界。
- 统一组件接口契约，降低组件使用成本。
- 规范父子组件通信与跨层级通信方式。
- 提高表单、表格、弹窗等高频交互的复用率。

## 2. 组件分类

| 分类 | 位置 | 说明 |
|------|------|------|
| 通用组件 | `src/components/` | 跨模块复用，与业务无关。 |
| 业务组件 | `src/modules/**/components/` | 模块私有，围绕具体业务对象组织。 |
| 布局组件 | `src/layout/` | 页面框架、侧边栏、顶部栏、404。 |

## 3. 通用组件

### 3.1 `pageTable`（`src/components/table/pageTable.vue`）

统一表格封装，职责：

- 渲染数据、列配置、加载状态。
- 支持搜索、排序、分页（客户端或服务端）。
- 支持行点击与行拖拽。

#### Props

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| `columns` | `Array` | 是 | 列定义，支持 `title`、`key`、`sortable`、`searchable`、`searchType`、`searchFilters`、`searchValue`、`width`、`render` 等。 |
| `tableData` | `Array` | 否 | 原始数据；未开启服务端分页时，内部完成分页、搜索、排序。 |
| `loading` | `Boolean` | 否 | 表格加载状态。 |
| `border` | `Boolean` | 否 | 是否显示边框，默认 `true`。 |
| `height` | `Number` | 否 | 表格高度。 |
| `currentPage` | `Number` | 否 | 当前页码，默认 `1`。 |
| `pageSize` | `Number` | 否 | 每页条数，默认 `20`。 |
| `pageSizes` | `Array` | 否 | 可选分页条数，默认 `[20, 30, 40, 50]`。 |
| `total` | `Number` | 否 | 服务端分页时的总条数。 |
| `serverPagination` | `Boolean` | 否 | 是否启用服务端分页，默认 `false`。路由表、模型定价列表开启此模式。 |
| `draggable` | `Boolean` | 否 | 是否支持行拖拽。 |

#### Events

| Events | 参数 | 说明 |
|--------|------|------|
| `dragDrop` | `(startIndex, endIndex)` | 行拖拽结束，返回原始数组下标。 |
| `on-row-click` | `(row, index)` | 行点击事件。 |
| `on-page-change` | `{ page, pageSize }` | 服务端分页时页码或每页条数变化。 |
| `on-search-change` | `filters` | 服务端分页时搜索条件变化。 |
| `on-sort-change` | `sortInfo` | 服务端分页时排序变化。 |

### 3.2 `CustomModal`（`src/components/CustomModal/index.vue`）

统一弹窗封装，职责：

- 提供确认/取消按钮、标题、内容。
- 支持单个按钮模式、loading 状态、禁用状态。

#### Props

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| `modal` | `Boolean` | 是 | 是否显示。 |
| `title` | `String` | 否 | 标题。 |
| `content` | `String` | 否 | 文本内容，支持 `\n` 换行。 |
| `okText` | `String` | 否 | 确认按钮文案。 |
| `cancelText` | `String` | 否 | 取消按钮文案。 |
| `loading` | `Boolean` | 否 | 确认按钮 loading 状态。 |
| `oneButton` | `Boolean` | 否 | 是否只显示确认按钮。 |
| `disableConfirm` | `Boolean` | 否 | 禁用确认按钮。 |
| `disableCancel` | `Boolean` | 否 | 禁用取消按钮。 |
| `width` | `String` | 否 | 弹窗宽度，默认 `30%`。 |

#### Events

| Events | 说明 |
|--------|------|
| `onOk` | 点击确认按钮。 |
| `onCancel` | 点击取消按钮。 |

### 3.3 `Expression`（`src/components/Expression/index.vue`）

条件表达式可视化编辑器，用于路由规则中的表达式配置。`body` 维度提供 `req_body_json_in` 与 `req_body_json_prefix_in`（按 JSON 字段前缀匹配，如 OpenRouter `openrouter/`）。

#### Props

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| `expression` | `String` | 否 | 初始表达式。 |
| `vars` | `Array` | 否 | 可用变量列表，组件内部自动拼接 `$` 前缀。 |
| `type` | `String` | 否 | 表达式类型，默认 `controller`，可选 `connController`。 |

#### Events

| Events | 参数 | 说明 |
|--------|------|------|
| `expressionChanged` | `{ expression, vars, errmsg }` | 表达式变更或后端校验后触发。 |

## 4. 业务组件模式

### 4.1 向导容器（以 Cluster 为例）

`modules/Clusters/components/index.vue`：

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| `currentCluster` | `Object` | 否 | 当前集群数据，编辑时传入。 |
| `clusterNames` | `Array` | 是 | 已有集群名称列表，用于新建时重名校验。 |
| `isAdd` | `Boolean` | 是 | 是否为新建模式。 |

| Events | 参数 | 说明 |
|--------|------|------|
| `submit` | 无 | 提交成功后通知父组件关闭抽屉并刷新列表。 |

### 4.2 子表单组件（如 `BaseConfig`）

| Props | 类型 | 必填 | 说明 |
|-------|------|------|------|
| `baseConfigData` | `Object` | 是 | 表单初始数据。 |
| `isAdd` | `Boolean` | 是 | 是否为新建。 |
| `reportFlag` | `Boolean` | 是 | 父组件通过翻转该值触发子组件校验与提交。 |
| `clusterNames` | `Array` | 是 | 用于重名校验。 |

| Events | 参数 | 说明 |
|--------|------|------|
| `submitData` | `{ topic: 'baseConfigData', data: Object }` | 校验通过后提交该步骤数据。 |

## 5. 数据流规范

### 5.1 父子组件通信

| 方向 | 方式 | 说明 |
|------|------|------|
| 父 → 子 | `props` | 数据、配置、标志位。 |
| 子 → 父 | `$emit` | 事件、提交数据、触发动作。 |
| 触发式提交 | 父组件翻转 `reportFlag` | 向导类表单统一由父组件触发子组件校验，避免子组件自行监听按钮。 |

### 5.2 跨层级通信

| 场景 | 推荐方式 | 禁用方式 |
|------|----------|----------|
| 父子组件 | `props` + `$emit` | 直接修改父组件数据、通过 `$parent` 调用方法。 |
| 兄弟组件 | 状态提升到共同父组件 | 全局事件总线（框架级事件除外）。 |
| 跨模块共享 | `store.js` | 直接引用其他模块内部组件。 |
| 框架级通知 | `this.$root.$emit` / `$root.$on` | 任意组件直接操作 `router`。 |

### 5.3 状态提升原则

当多个子组件需要共享状态时，状态应提升到最近的公共父组件（如向导容器）。

## 6. 组件设计约束

1. **props 不可变**：子组件不直接修改 `props`，需要修改时通过事件通知父组件。
2. **单一职责**：一个组件只负责一个明确的交互或展示任务。
3. **通用组件无业务逻辑**：通用组件不感知业务对象，只接收配置和数据。
4. **业务组件不外泄**：业务组件仅在模块内部使用，不跨模块引用。
5. **异步校验回传**：如 `Expression` 组件内部调用后端校验接口，校验结果通过事件回传，由父组件决定是否允许提交。

## 7. 扩展通用组件 checklist

新增通用组件时：

- [ ] 在 `src/components/` 下创建独立目录或文件。
- [ ] 定义清晰的 Props 与 Events 接口。
- [ ] 在本文档中补充接口契约说明。
- [ ] 确保不依赖特定业务模块数据。
- [ ] 如需要新增 i18n key，同步更新 `en.js` 与 `zh.js`。
