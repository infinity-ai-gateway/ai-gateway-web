# 证书管理模块细节设计

## 1. 模块定位

`Cert` 管理 AI 网关 TLS 证书，支持上传 PEM 证书与私钥、查看过期时间、切换全局默认证书及删除非默认证书。全局必须有且仅有一个默认证书。

## 2. 路由与入口

| 路由 | name | 组件 | 说明 |
|------|------|------|------|
| `/cert` | `certs.list` | `modules/Cert/index.vue` | 证书列表与全局默认证书选择。 |

导航：`nav_tree.toml` 中 `certs.list` 归属「资源管理」分组；侧栏图标为 `iconfont icon-cert`（`navItem.vue`）。

## 3. 页面结构

### 3.1 列表页

- 顶部「创建证书」按钮打开 40% 宽度抽屉。
- **全局缺省证书**：列表上方 `Select` 展示当前默认证书，切换时二次确认后调用 `PATCH certificates/{cert_name}/default`。
- 使用 `pageTable` 展示以下列：
  - `cert_name`（Tooltip 展示 `description`）
  - `is_default`（默认证书显示 Tag）
  - `expired_date`（服务端解析，格式化为 `YYYY-MM-DD HH:mm:ss`）
  - 操作列：删除（`is_default === true` 时按钮禁用并提示「默认证书不可删除」）

### 3.2 创建抽屉

- 使用 `components/Create.vue`。
- 字段：`cert_name`、`description`、证书文件、私钥文件、「设为默认」Checkbox。
- **过期时间预览**：上传证书后由 `utils/cert.js` 的 `parseCertExpiredDate` 解析首个 PEM 块 `notAfter` 并只读展示；未上传时显示占位文案；解析失败不弹错，最终以服务端解析为准。
- **首证逻辑**：系统中尚无默认证书时（`defaultIsDefault` prop），`is_default` 自动为 `true` 且 Checkbox 禁用。

## 4. 组件清单

| 组件 | 职责 | 关键 Props | 事件 |
|------|------|------------|------|
| `index.vue` | 列表、全局默认切换、删除 | — | — |
| `Create.vue` | 新建证书表单 | `defaultIsDefault` | `submit` |

## 5. 表单字段与校验

| 字段 | 校验 | 说明 |
|------|------|------|
| `cert_name` | 2–64 字符；字母/数字/`_`/`-`/`.`；不能以 `_`、`-`、`.` 开头或结尾；无空白 | `CertNameRegCheck`（`utils/const.js`）。 |
| `description` | 2–256 字符；不含控制字符 | `CertDescriptionRegCheck`。 |
| `cert_file_content` | 必填；合法 PEM X.509 | 通过 `Upload` 的 `before-upload` 读取文件内容。 |
| `key_file_content` | 必填；合法 PEM 私钥 | 须与证书匹配，由服务端校验。 |
| `is_default` | 布尔 | 提交字段；首证场景由父组件强制为 `true`。 |

提交体**不含** `expired_date`、`cert_file_name`、`key_file_name`（与 OpenAPI 对齐）。

## 6. 数据流

```
Cert/index.vue
    ├── getCerList() → GET certificates → tableData
    ├── Select 切换默认 → Modal 确认 → PATCH certificates/{cert_name}/default
    ├── onDel → DELETE certificates/{cert_name}
    └── Drawer → Create.vue → POST certificates → 刷新列表
```

## 7. OpenAPI 消费映射

| 组件 | 方法 | 相对 URL | 说明 |
|------|------|----------|------|
| `index.vue` | `GET` | `certificates` | 列表。 |
| `index.vue` | `POST` | `certificates` | 创建（`Create.vue` 触发）。 |
| `index.vue` | `DELETE` | `certificates/{cert_name}` | 删除。 |
| `index.vue` | `PATCH` | `certificates/{cert_name}/default` | 设置默认证书。 |

接口定义见 `design-docs/api-define/OpenAPI接口定义/certificates.md`。

## 8. 边界情况

- 切换全局默认证书时，若用户取消确认，`Select` 回滚为当前默认证书名。
- 列表为全量拉取，无服务端分页；列搜索与排序由 `pageTable` 前端处理。
- 当前 UI 未实现证书更新（PUT）；如需轮换证书内容，需删除后重建或后续扩展编辑能力。
