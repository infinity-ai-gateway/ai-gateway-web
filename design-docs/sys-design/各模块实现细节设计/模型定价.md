# ModelPrices 模块细节设计

## 1. 模块定位

`ModelPrices` 维护「提供商 + 模型名 + 模式」维度的价格信息，供网关按集群 LLM 配置中的 `provider` 做费用核算。入口：资源管理 → 模型定价。

## 2. 路由与入口

| 路由 | name | 组件 | 说明 |
|------|------|------|------|
| `/model-prices` | `ModelPrice.list` | `modules/ModelPrices/index.vue` | 定价列表、导入、抽屉 CRUD。 |

内部组件：

- `ModelPriceUpsert.vue`：创建 / 编辑。
- `ModelPriceView.vue`：只读详情（含 `create_time` / `update_time`）。
- `ModelPriceImport.vue`：YAML 导入（replace / merge）。

## 3. 页面结构

### 3.1 列表页

- `pageTable` 开启 `server-pagination`，请求 `GET model-prices`（`page` / `page_size` + 筛选）。
- 列：提供商（下拉筛选）、模型名、模式（下拉筛选）、归一化模型名、操作（详情 / 编辑 / 删除）。
- 顶部：「+ 新增定价」、「YAML 导入」。

### 3.2 创建 / 编辑抽屉

表单分区：

| 分区 | 字段 | 校验要点 |
|------|------|----------|
| 基本信息 | `provider`、`model`、`base_model`、`mode` | 必填；`(provider, model, mode)` 组合不可重复。 |
| 能力 / 参数 | `capabilities`、`supported_parameters` | 多选标签，枚举来自 OpenAPI。 |
| 限制 | `limits` 动态键值 | 键不重复；值须为非负整数。 |
| 价格 | `prices` 动态键值 | 至少一条；键不重复；值须为非负数。 |
| 元数据 | `metadata.source`、`metadata.notes` | source 若填写须为合法 URL。 |

时间字段只读，使用 `create_time` / `update_time`（Unix 秒）。

### 3.3 YAML 导入

- 模式：`replace`（全量替换）、`merge`（增量合并）。
- 上传 `.yaml` / `.yml`，前端用 `js-yaml` 做结构预校验后 `POST model-prices/import`。

## 4. 组件清单

| 组件 | 职责 | 关键 Props | 事件 |
|------|------|------------|------|
| `index.vue` | 列表、分页筛选、打开抽屉/导入 | — | — |
| `ModelPriceUpsert.vue` | 新建/编辑表单 | `currentData` | `submit`、`cancel` |
| `ModelPriceView.vue` | 只读详情 | `currentData` | — |
| `ModelPriceImport.vue` | YAML 导入 | — | `submit`、`error` |

## 5. 数据流

```
ModelPrices/index.vue
    ├─ GET /model-prices → 分页列表 + provider 筛选项
    ├─ Upsert → GET /model-prices 查重 → POST 或 PUT /model-prices/{id}
    ├─ View → 展示 currentData（含时间戳）
    ├─ DELETE /model-prices/{id}
    └─ Import → POST /model-prices/import?mode=replace|merge
```

## 6. OpenAPI 消费映射

| 组件 | 方法 | 相对 URL | 说明 |
|------|------|----------|------|
| `index.vue` | `GET` | `model-prices` | 分页列表。 |
| `index.vue` | `DELETE` | `model-prices/{id}` | 删除。 |
| `ModelPriceUpsert.vue` | `GET` | `model-prices` | 组合查重（兼容空对象 / 空 list，避免误报）。 |
| `ModelPriceUpsert.vue` | `POST` | `model-prices` | 新建。 |
| `ModelPriceUpsert.vue` | `PUT` | `model-prices/{id}` | 更新。 |
| `ModelPriceImport.vue` | `POST` | `model-prices/import` | YAML 导入。 |

## 7. 边界情况

- 查重接口可能返回单条记录或分页 `{ list, pagination }`，需同时判断 `data.id` 与 `data.list.length`。
- `price_currency` 固定 `RMB`，请求体不传。
- 集群 LLM 的 `provider` 字段与本表 `provider` 对齐，用于费用核算。
