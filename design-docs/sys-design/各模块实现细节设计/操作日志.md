# 操作日志模块细节设计

## 1. 模块定位

`OperationLogs` 提供 AI 网关操作审计日志的只读查询能力，支持时间范围筛选、列级搜索与服务端分页，并在详情抽屉中展示变更摘要（含脱敏后的 before/after JSON）。

## 2. 路由与入口

| 路由 | name | 组件 | 说明 |
|------|------|------|------|
| `/operation-logs` | `OperationLog.list` | `modules/OperationLogs/index.vue` | 操作日志列表与详情。 |

导航：`nav_tree.toml` 中 `OperationLog.list` 为顶层独立菜单；侧栏图标为 `ivu-icon-md-list-box`。

## 3. 页面结构

### 3.1 筛选栏

- 起始时间、结束时间：`DatePicker`（`datetime`，格式 `yyyy-MM-dd HH:mm:ss`）。
- 「查询」按钮：重置到第 1 页并携带 `start_time` / `end_time`（Unix 秒）请求列表。

### 3.2 列表页

- 使用 `pageTable`，开启 `server-pagination`（默认 `pageSize` 20）。
- 表格列：

| 列 | 搜索 | 说明 |
|----|------|------|
| `operator_name` | 模糊 | 操作人。 |
| `action` | 下拉 | `create` / `update` / `delete` / `reset` / `import` / `bind` / `unbind`，Tag 着色。 |
| `resource_type` | 下拉 | 如 `entity`、`api_key`、`certificate` 等。 |
| `resource_name` | 模糊 | 资源名称。 |
| `status` | 下拉 | `1` 成功 / `2` 失败，Tag 展示。 |
| `created_at` | — | 格式化为本地时间字符串。 |
| 操作 | — | 「详情」按钮打开抽屉。 |

- 列头排序当前仅占位（`onSortChange` TODO，未接服务端排序）。

### 3.3 详情抽屉

- 右侧滑出，宽度 **720px**，标题「日志详情」。
- 不展示 `id`、`log_id`、`operator_id`。
- 字段按两列布局排列：操作者类型、操作人、操作动作、资源类型、资源 ID、资源名称、父级资源 ID、结果、错误信息（条件）、变更摘要（条件）、请求路径、请求方式、客户端 IP、User-Agent、操作时间。
- **变更摘要**：`change_summary.before` / `after` 使用 `vue-json-viewer` 可折叠展示；`diff_keys` 以逗号拼接列表展示。

## 4. 组件清单

| 组件 | 职责 | 关键 Props | 事件 |
|------|------|------------|------|
| `index.vue` | 筛选、列表、分页、详情抽屉 | — | — |

本模块无 `components/` 子目录，逻辑集中在单文件组件内。

## 5. 查询参数

| 参数 | 来源 | 说明 |
|------|------|------|
| `page` / `page_size` | 分页组件 | 服务端分页。 |
| `operator_name` | 列搜索 | 模糊匹配。 |
| `action` | 列搜索 | 精确匹配。 |
| `resource_type` | 列搜索 | 精确匹配。 |
| `resource_name` | 列搜索 | 模糊匹配。 |
| `status` | 列搜索 | `1` 或 `2`。 |
| `start_time` / `end_time` | 筛选栏 | Unix 秒；由 `toUnixTimestamp` 从 DatePicker 值转换。 |

## 6. 数据流

```
OperationLogs/index.vue
    ├── mounted → fetchData()
    ├── filter-bar 查询 → page=1 → fetchData()
    ├── pageTable 分页/列搜索 → fetchData()
    └── 详情按钮 → drawerVisible + currentData（列表行数据，无二次请求）
```

## 7. OpenAPI 消费映射

| 组件 | 方法 | 相对 URL | 说明 |
|------|------|----------|------|
| `index.vue` | `GET` | `operation-logs` | 分页列表；`openapi: true`。 |

响应结构：`Data.list` 为日志数组，`Data.pagination.total`（或兼容字段 `Data.total`）为总条数。

接口定义见 `design-docs/api-define/OpenAPI接口定义/operation-logs.md`。

## 8. 边界情况

- `operator_type`：`0` 为用户，`1` 为 Token，详情中通过 `operatorTypeLabel` 映射文案。
- `change_summary` 中敏感字段已由后端脱敏，前端直接展示 JSON。
- 加载失败时统一提示 `operationLogs.loadFailed`。
- 详情抽屉 `transfer` 到 `body`，样式使用独立选择器（非嵌套在 `.operation-logs` 下）。
