# Providers 模块细节设计

## 1. 模块定位

`Providers` 管理模型服务商（`/providers`）：持有后端实例池、模型协议、模型发现端点、鉴权 Key 明文与模型列表。集群通过 `llm_config.provider` **引用**服务商名称，不再在集群向导中维护实例池。

入口：资源管理 → 模型服务商。

## 2. 路由与入口

| 路由 | name | 组件 | 说明 |
|------|------|------|------|
| `/providers` | `Provider.list` | `modules/Providers/index.vue` | 列表、创建/编辑/详情抽屉。 |

内部组件：

- `ProviderUpsert.vue`：创建 / 编辑（嵌入 `InstancePool`）。
- `ProviderView.vue`：只读详情。

## 3. 页面结构

### 3.1 列表页

- `pageTable` 服务端分页：`GET /providers`（`page` / `page_size`，可选 `model_protocol`）。
- **协议**：下拉筛选走后端 Query。
- **名称 / 描述 / 模型**：仅对当前页 `tableData` 前端模糊过滤（`localFilters` → `displayTableData`）。
- **模型列**：最多 2 个 Tag，超出显示 `+N`，悬停 Tooltip 展示完整列表。
- 操作列：详情、**查询模型价格**、编辑、删除。

**查询模型价格**：`$router.push({ name: 'ModelPrice.list', query: { provider: row.name, autoView: '1' } })`，在模型定价页按提供商筛选并自动打开第一条定价详情（`provider` 须与定价表 `provider` 一致）。

### 3.2 创建 / 编辑

分区与校验要点：

| 分区 | 要点 |
|------|------|
| 基本信息 | `name`（ProviderName 规则）、`description` |
| 实例池 | 复用 `Clusters/components/InstancePool.vue`；IP 模式底栏统一校验提示；提交 `instance_pool[].name === addr` |
| 模型服务配置 | `model_protocols`、`model_endpoint`（schema + uri）；host 展示来自实例池 |
| 模型列表 | 仅能通过 `POST /providers/tools/discover-models` 回填；`el-select` 多选、可删 tag、不可手填；「获取」置灰条件见下 |
| 服务鉴权 Keys | `keys[].name` + `keys[].key`；同 provider 内 name 唯一 |

**「获取」可用条件**：已选 `model_protocols`；`instance_pool` 至少一条 `addr` 非空。点击后直接调工具接口回填，无确认框、无成功 toast，须提交表单持久化。

### 3.3 详情

`ProviderView.vue` 只读展示各分区（Key 值掩码）。

## 4. 组件与数据流

```
Providers/index.vue
    ├─ GET /providers → 分页列表
    ├─ GET /providers/{name} → 编辑/详情回填
    ├─ POST /providers | PATCH /providers/{name}
    ├─ DELETE /providers/{name}（被集群引用 409）
    └─ Drawer → ProviderUpsert / ProviderView
          └─ InstancePool（pool-change 驱动 endpoint host 展示）
          └─ discover-models → 回填 models
```

`InstancePool.vue` 导出 `formatInstancePoolForApi`、`parseInstancePool` 等，供本模块与集群侧工具引用（集群向导不再嵌入实例池步骤）。

## 5. OpenAPI 消费映射

| 组件 | 方法 | 相对 URL | 说明 |
|------|------|----------|------|
| `index.vue` | `GET` | `providers` | 分页列表。 |
| `index.vue` | `GET` | `providers/actions/get-provider-names` | 创建时名称去重列表（非列表页 mounted 全量拉取）。 |
| `index.vue` | `GET` | `providers/{provider_name}` | 详情。 |
| `index.vue` | `DELETE` | `providers/{provider_name}` | 删除。 |
| `ProviderUpsert.vue` | `POST` | `providers` | 新建。 |
| `ProviderUpsert.vue` | `PATCH` | `providers/{provider_name}` | 更新；`keys`、`instance_pool` 全量替换。 |
| `ProviderUpsert.vue` | `POST` | `providers/tools/discover-models` | 无状态模型发现（Body 传连接参数，不读写 Provider 资源）。 |

## 6. 边界情况

- 删除时仅集群引用阻塞（`409`）；`model-prices` 同名不阻塞删除。
- 实例 IP 重复提示使用「实例 IP 和端口不能重复」（不含「域名」文案）。
- 域名模式实例池：单条 `addr` + `port` 随 schema（http→80，https→443）。
