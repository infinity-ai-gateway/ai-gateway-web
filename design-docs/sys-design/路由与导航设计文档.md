# AI Gateway Web 路由与导航设计文档

## 1. 设计目标

- 定义前端路由表，实现按功能模块的按需加载（代码分割）。
- 通过路由守卫完成鉴权、语言包加载与导航拦截。
- 菜单由后端导航元数据驱动，保持前后端权限一致。

## 2. 技术栈

| 库/能力 | 说明 |
|---------|------|
| vue-router 3.x | 路由管理，采用 `history` 模式。 |
| require.ensure | 按路由维度进行代码分割，降低首屏加载体积。 |
| connect-history-api-fallback | 开发服务器支持 HTML5 History API 回退。 |

## 3. 路由文件结构

```
src/router/
├── router.js    # 路由配置数组
└── instance.js  # VueRouter 实例创建与导出
```

## 5. 代码分割

所有业务路由使用 `require.ensure` 进行懒加载，示例：

```js
{
  component: (r) =>
    require.ensure(
      [],
      () => r(require('../modules/Clusters')),
      'cluster.list'
    ),
  path: 'cluster',
  name: 'AICluster.list',
}
```

- `chunkName` 与路由 `name` 保持一致，便于调试。
- 布局框架与登录页单独打包。

## 6. 路由实例配置

`src/router/instance.js`：

```js
const router = new VueRouter({
  mode: 'history',
  routes: routerConfig
});
```

- 使用 `history` 模式，需要服务端/代理配合回退到 `index.html`。
- 开发环境通过 `connect-history-api-fallback` 支持。

## 7. 路由守卫

路由守卫注册在 `src/main.js`：

```
router.beforeEach
  ├─ 启动 NProgress
  ├─ 异步加载当前语言包
  ├─ 调用 checkRole(to) 鉴权
  │    ├─ 未登录 → 跳转登录页
  │    ├─ 非管理员 → 提示非法访问
  │    ├─ 目标路由不在导航树中 → 跳转登录页
  │    └─ 通过 → 继续导航
  └─ 根据鉴权结果处理跳转或弹窗提示
router.onError
  └─ 捕获 chunk 加载失败并重新导航
router.afterEach
  └─ 结束 NProgress
```

## 8. 鉴权与导航元数据

鉴权逻辑由 `src/utils/authorize.js` 提供：

1. 首次访问时，若 `store.meta` 为空，则请求后端 `meta` 接口（`GET /open-api/v1/meta`）。
2. 将后端返回的导航元数据存入 `store`。
3. 判断用户登录态与 `is_admin` 标志。
4. 对非登录页，检查目标路由 `name` 是否存在于导航树中。
5. 例外路由 `product.home` 可直接放行。

## 9. 导航菜单渲染

- 菜单数据来自 `store.getNavRoot()`，即后端返回的 `meta.nav.admin` 树。
- 菜单项通过 `id`（与路由 `name` 对应）绑定。
- 点击菜单后通过 `this.$router.push({ name: menuId })` 跳转。
- 当前激活项由 `$route.name` 驱动。
- 菜单组件位于 `src/layout/sidebarNav.vue`。
- 菜单图标在 `src/layout/sidebar/navItem.vue` 中按路由 `name` 映射，例如 `certs.list` → `iconfont icon-cert`，`OperationLog.list` → `ivu-icon-md-list-box`。
- 后端导航树（`ai-gateway-api/conf/nav_tree.toml`）中，`certs.list` 归属「资源管理」分组；`OperationLog.list` 为顶层独立菜单项，与路由管理、消费者管理等并列。

## 10. 导航取消事件

当用户在表单未保存时离开页面，模块可调用 `notifyNavigationCancelled`（来自 `utils/navigation.js`）并通过 `this.$root.$emit` 触发框架级通知，避免路由直接跳转导致状态丢失。

## 11. 设计约束

1. 路由 `name` 必须唯一，且与后端导航元数据中的 `id` 保持一致。
2. 新增业务页面必须注册到 `router.js`，并使用 `require.ensure` 懒加载。
3. 未登录或非法访问时，统一由 `authorize.js` 决定跳转目标。
4. 菜单权限由后端控制，前端不维护硬编码菜单。
