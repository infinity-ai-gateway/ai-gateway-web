# AI Gateway Web 国际化设计文档

## 1. 设计目标

- 支持中/英双语界面切换。
- 所有界面文本通过 i18n key 获取，避免硬编码。
- 组件库（iView）文案与业务文案统一合并到同一语言包。
- 切换语言时无需刷新页面，异步加载对应语言包。

## 2. 技术栈

| 库/能力 | 说明 |
|---------|------|
| vue-i18n 8.x | 国际化核心库。 |
| iView locale | iView 组件库自带 `en-US`、`zh-CN` 语言包。 |
| 语言包文件 | `src/i18n/en.js`、`src/i18n/zh.js`。 |

## 3. 文件结构

```
src/i18n/
├── en.js   # 英文语言包
└── zh.js   # 中文语言包
```

```
src/utils/i18n.js   # 国际化初始化与语言切换工具
```

## 4. 初始化配置

`src/utils/i18n.js`：

```js
import Vue from 'vue';
import VueI18n from 'vue-i18n';
import en from '../i18n/en';
import zh from '../i18n/zh';

import iView from 'iview';
import iview_en from 'iview/dist/locale/en-US';
import iview_zh from 'iview/dist/locale/zh-CN';

Vue.use(VueI18n);
Vue.locale = () => {};

const messages = {
  en: Object.assign(en, iview_en),
  zh: Object.assign(zh, iview_zh)
};

export const i18n = new VueI18n({
  locale: getLang(),
  fallbackLocale: 'en',
  messages
});

Vue.use(iView, {
  i18n: (key, value) => i18n.t(key, value)
});
```

- 业务语言包与 iView 语言包合并到同一 `messages` 对象中。
- 默认回退语言为英文（`fallbackLocale: 'en'`）。
- iView 组件通过 `i18n` 函数读取合并后的语言包。

## 5. 语言切换机制

```js
export function setLang(lang) {
  i18n.locale = lang;
  localStorage.setItem('lang', lang);
}

export function getLang() {
  return localStorage.getItem('lang') || 'en';
}

export const langSet = {
  zh: '中文',
  en: 'English'
};

const loadedLanguages = ['en'];
export function loadLanguageAsync(lang) {
  if (i18n.locale !== lang) {
    if (!loadedLanguages.includes(lang)) {
      return import(`../i18n/${lang}.js`).then(msgs => {
        i18n.setLocaleMessage(lang, msgs.default[lang]);
        loadedLanguages.push(lang);
        return setLang(lang);
      });
    }
    return Promise.resolve(setLang(lang));
  }
  return Promise.resolve(lang);
}
```

### 切换流程

1. 路由守卫中调用 `loadLanguageAsync(lang)`。
2. 若目标语言未加载，动态 `import` 对应语言文件。
3. 设置 `i18n.locale` 并写入 `localStorage.lang`。
4. 组件响应式更新，界面重新渲染。

## 6. 使用规范

### 6.1 模板中

```vue
<template>
  <Button>{{ $t('com.createX', { obj: $t('cluster.name') }) }}</Button>
</template>
```

### 6.2 脚本中

```js
import { i18n } from '@/utils/i18n';
const msg = i18n.t('com.tipDelSucc');
```

### 6.3 语言包结构

按业务领域组织 key：

```js
export default {
  en: {
    com: { /* 通用文案 */ },
    cluster: { /* 集群相关 */ },
    route: { /* 路由相关 */ },
    apiKey: { /* API Key 相关 */ },
    entity: { /* Entity 相关 */ },
    user: { /* 用户相关 */ },
    login: { /* 登录相关 */ }
  }
};
```

## 7. 设计约束

1. **禁止硬编码**：所有用户可见文本必须走 `$t` 或 `i18n.t`。
2. **key 命名规范**：采用 `<domain>.<key>` 的层级命名，如 `cluster.name`、`com.createX`。
3. **双语同步**：新增或修改文案时，必须同时更新 `en.js` 与 `zh.js`。
4. **语言包只加载一次**：通过 `loadedLanguages` 数组缓存，避免重复加载。
5. **请求头带语言**：`request.js` 自动注入 `Accept-Language` 请求头，后端可据此返回对应语言的错误信息。

## 8. 扩展语言

如需新增语言（如日语）：

1. 新增 `src/i18n/ja.js`。
2. 在 `src/utils/i18n.js` 中引入并加入 `messages`。
3. 在 `langSet` 中补充语言名称。
4. 更新语言切换组件。
