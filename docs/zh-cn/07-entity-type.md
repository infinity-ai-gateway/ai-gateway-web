# 07 消费者管理：Entity 类型

**Entity（调用方组织）**类型是对调用方组织的一种分类维度（如部门、团队、个人），用于定义组织的层级关系。你可以把 Entity 理解为"部门""团队"或"项目组"。

进入 消费者管理 → Entity 管理（组织管理），切换到 **Entity 类型管理** 页签。

## 7.1 类型列表

![类型列表](images/05-type-list.png)

**表格列说明**：

| 列名 | 说明 |
| --- | --- |
| 类型名 | 类型标识，支持按名称搜索 |
| 描述 | 类型说明 |
| 级别 | 取值 1-5，**数字越小代表层级越高**（1 = 公司级，2 = 部门级，3 = 团队级，4 = 小组级，5 = 个人级）；支持下拉筛选 |
| 创建时间 | 类型创建的时间 |
| 操作 | 编辑、删除 |

列表上方有「创建类型」按钮（右上角）。

## 7.2 创建类型

点击列表上方的「创建类型」按钮，右侧弹出创建抽屉。

![创建类型](images/05-type-create.png)

**表单字段**：

| 字段 | 必填 | 默认值 | 格式要求 | 说明 |
| --- | --- | --- | --- | --- |
| 类型名 | 是 | 空 | 1-32 字符；仅含小写字母、数字、下划线(`_`)、连字符(`-`)；不能以下划线或连字符开头或结尾 | 全局唯一，创建后不可修改。如 `dep`、`team` |
| 描述 | 否 | 空 | 最多 1024 字符 | 类型说明，如「一级部门」 |
| 级别 | 是 | `1` | 取值 1-5 的整数 | 数字越小层级越高。例如：1 对应"公司"，2 对应"部门"，3 对应"团队"。高级别（数字小）可以作为低级别（数字大）的父级，比如"公司"下面可以有"部门" |

抽屉底部有「取消」和「确定」按钮。点击「确定」提交表单，创建成功后关闭抽屉并刷新列表，提示「创建成功！」。

## 7.3 编辑类型

点击操作列的「编辑」按钮，右侧弹出编辑抽屉。字段预填充，其中类型名为灰色禁用状态不可修改，描述和级别可编辑。

## 7.4 删除类型

点击操作列的「删除」按钮，弹出确认框「是否删除Entity类型 {类型名}？」。确认后立即删除，提示「删除成功!」，列表自动刷新。

> 注意：类型下存在组织时无法删除，需先清理关联的组织数据。

## 7.5 注意事项

- 类型名创建后不可修改，命名建议简洁且有业务含义（如 `dep`、`team`）。
- 层级关系规则：**父组织的类型级别数字必须比当前组织的级别数字小**。例如当前组织是"团队"（级别 3），那它的父组织只能是"公司"（级别 1）或"部门"（级别 2），不能反过来。
- 删除类型前需确保该类型下不存在任何组织。
