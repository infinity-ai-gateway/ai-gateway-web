# 03 资源管理：AI 网关实例池

实例池登记**数据面转发引擎（BFE）**的实例地址。数据面负责接收客户端请求、执行鉴权 / 限流 / 配额 / 路由并转发到业务集群。

## 3.1 列表

资源管理 → AI 网关实例池。列表展示机器名、IP、端口、状态。单机部署时，部署阶段已自动登记引擎地址，确认列表非空即可。

![实例池列表](images/03-pool-list.png)

## 3.2 编辑与新增

点击「编辑」进入编辑模式，可新增 / 删除实例行：

![编辑模式](images/03-pool-edit-mode.png)

点击「新增」添加一行，填写机器名、IP、端口后保存：

![新增实例](images/03-pool-create.png)

## 3.3 字段说明

| 字段 | 必填 | 说明 |
| ------ | ------ | ------ |
| 机器名 | 是 | 便于识别的名称，如 `bfe-1` |
| IP | 是 | 数据面引擎所在机器 IP |
| 端口 | 是 | 引擎管理 / 转发端口，与部署配置一致 |

> 注意：实例池**不填**后端模型服务地址。模型服务地址在业务集群的「实例配置」中填写，见 [04 章](04-resource-cluster.md)。
