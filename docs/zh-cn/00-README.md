# AI 网关管理控制台用户手册

本手册面向**控制台使用者**：运维 / 平台同学通过 Web 控制台完成资源接入、消费者治理、路由配置与日常运维。手册基于当前版本控制台真实截图编写，UI 变更后截图可一键重截。

## 约定说明

- 截图均为真实环境截取，示例数据（集群名 `demo-cluster`、组织 `dev-team` 等）与 07 章保持一致；
- 文中「→」表示菜单层级，如 资源管理 → AI 业务集群；
- 必填字段以 `*` 标注；
- 控制台地址默认为 `http://<控制台IP>:8088`，默认管理员账号见部署文档。

## 模块全景

```text
资源管理 ─ AI 网关实例池（数据面引擎地址）
        └ AI 业务集群（后端模型服务 + 哈希策略）
消费者管理 ─ API Key 管理（调用凭证）
          └ Entity 管理（类型 / 组织，配额与限流挂载点）
路由管理 ─ 路由表（Global / Entity / API-Key 三级优先级）
用户管理 ─ 控制台账号与 Token
```
