# 12 附录

## A. 术语表

| 术语 | 说明 |
| ------ | ------ |
| 数据面 / BFE | 接收并转发请求的引擎，执行鉴权、限流、配额、路由 |
| 控制台 | Web 管理界面（本文档对象） |
| 实例池（数据面） | AI 网关实例池中登记的数据面引擎地址清单 |
| 模型服务商 | 持有后端实例池、模型协议、模型列表与服务鉴权 Key 明文的资源；集群通过「所属服务商」引用 |
| 业务集群 | 引用服务商，配置协议 / 超时 / 健康检查 / 转发模型与 Key 权重等转发策略 |
| Entity | 调用方分组（组织），挂载配额 / 限流 / 模型访问控制 |
| Entity 类型 | 组织层级定义（级别数字越小层级越高） |
| API Key | 调用凭证，请求头 `Authorization: <Key>`（不需要 Bearer 前缀） |
| 路由表 | Global / Entity / API-Key 三级，优先级依次升高 |
| TPM | Tokens Per Minute，滑动窗口 Token 限流 |
| RPM | Requests Per Minute，固定窗口请求限流 |
| 配额 | 周期内 Token 或金额总量控制，不足拒绝并回滚已扣部分 |
| 会话保持 | 同一客户端请求稳定落到同一后端实例（哈希策略） |
| 备用集群 / fallbacks | 路由规则中目标集群失败时的回落目标 |
| 转发模型 | 集群从大模型配置中选择的、允许转发的模型子集 |
| Key 路由策略 | 多 Key 的轮询与重试策略 |
| Key 亲和性 | 同一会话绑定同一 Key，需 Redis 支持 |
| 分段计价 / peak | 服务商忙时时间段，用于模型定价分时段价格匹配 |
| 模型定价 | 模型价格信息维护，用于费用核算 |

## B. 常见错误提示对照

| 提示 / 现象 | 含义 | 处理 |
| ------ | ------ | ------ |
| 数据重复 | 同名记录已存在（服务商 / 集群 / 类型 / 组织 / 规则等） | 换名或先删除旧记录 |
| 删除失败，该服务商可能仍被集群引用 | 服务商仍被业务集群使用 | 先修改或删除引用集群 |
| 参数非法 exec-api … connection refused | 模型发现接口不可达 | 检查服务商实例池地址 / 端口 / 网络 |
| 权重之和必须等于100 | 规则目标或 Key 权重校验失败 | 调整权重使和为 100 |
| 目标集群和模型组合不能重复 | 同一规则内目标重复 | 删除重复目标 |
| 备用集群和模型组合不能重复 | 备用与目标重复 | 删除重复项 |
| 哈希头部必填 | 哈希策略为 CLIENT_ID_* 但未填头部 | 填写如 `x-client-id` 或 `Cookie:USERID` |
| 401 | Key 错误 / 过期 / IP 不在允许子网 | API Key 管理核对 |
| 403 | 模型不在允许列表或在禁止列表 | 核对 Key / 组织允许模型，见 [8.5 节](08-entity.md) |
| 429 | 触发 TPM / RPM 限流 | 调整限流规则，见 [8.6 节](08-entity.md) |
| 配额错误 | 配额余额不足 | 查看余量或重置配额 |
